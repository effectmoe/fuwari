# effect.moe Blog LLMO Template

effect.moe のブログ記事は、公開前にこのテンプレートを必ず確認する。
目的は、単なる商品紹介ではなく、外部ソースや観察事実を起点にした「読まれる記事」として公開し、最後に自然な形で AI CENTRAL / AI CRAWL / AI CITATION / AI講座へ接続すること。

## 基本方針

- 記事は外部記事、公開投稿、ブックマーク、モニタリング結果、Wikiの知見のいずれかを起点にする。
- 冒頭から自社商品を売り込まない。先に読者の課題、外部論点、技術的背景を説明する。
- 自社サービスへの導線は、本文で価値を出したあとに置く。
- 数字、引用、実績、外部記事の主張は、必ず本文または `relatedLinks` で出典を示す。
- 実在クライアント名、個人情報、特定につながる業種と製品名の組み合わせは出さない。
- AI検索、LLMO、SEO、CTA、CV、AI流入、引用、構造化データなどの記事テーマは、専門用語の説明を先に置く。

## 記事本文の型

### 1. 外部ソースから始める

最初に、モニタリングやブックマークで見つけた記事、公開投稿、統計、検索変化を提示する。

例:

> 海外SEOメディアでは、AI検索によって従来の検索流入やCTA設計が揺らぎ始めている、という議論が増えています。

### 2. 何が問題なのかを一般化する

読者が自社に置き換えられるように、個別記事の話を一般論へ変換する。

例:

> 問題は、検索順位が下がったことだけではありません。ユーザーが検索結果を読む前に、AIが候補を要約し、比較し、推薦する場面が増えていることです。

### 3. effect.moe の見解を述べる

賛同、批評、補足を明確に書く。ここで自社商品名を出してもよいが、まだ売り込まない。

例:

> 私たちは、SEOが終わったとは考えていません。ただし、SEOだけで説明できない接点が増えたことは事実だと見ています。

### 4. 実務で確認すべきことへ落とす

読者が次に何を見ればよいかを箇条書きで整理する。

- AIが自社サイトの存在を把握しているか
- AI回答に自社名、ページ、サービスが登場するか
- 代わりにどの競合や媒体が出ているか
- 引用されるページとされないページの差分は何か
- CTAや相談導線がAI時代の検索行動に合っているか

### 5. 自社サービスへの自然な導線

本文の最後に、課題解決の選択肢としてサービスを紹介する。

例:

> このような状況を自社サイトで確認するために、effect.moe では AI CRAWL と AI CITATION を提供しています。AI CRAWL はAI側からの接点を整理し、AI CITATION はAI回答に自社が登場するかを測ります。

## 記事末ブロックの順序

記事本文に近い順に並べる。記事本文の理解に必要なものを上に置き、会社・商品・著者などの案内は下に置く。

1. 関連リンク
2. 用語の補足・よくある質問
3. 参照した外部記事・ブックマーク
4. 著者情報、構造化ペディア、月額サービスなどのサイト共通案内

注意:

- 記事内FAQの下に、総合FAQページへの「もっと詳しい用語集・よくある質問を見る」のような導線は置かない。
- 総合FAQに記事固有のFAQがない場合、読者に「続きがある」と誤認させるため。
- FAQから内部リンクを張る場合は、回答本文の中で本当に関連するページへだけ張る。

## 画像と漫画のルール

- ヘッダー画像とサムネイル画像は別アスペクト比で作る。
- ヘッダー画像は記事ページで見切れない構図にする。
- サムネイル画像はブログカードで読める構図にする。
- 漫画は既存のメインキャラクターを使う。
- `manga_tldr` は漫画のコマとして読める内容にする。単なる説明スライドにしない。
- 画像内の文字は本文HTMLでも説明し、画像だけに重要情報を閉じ込めない。

## SEO / LLMO チェック

公開前に必ず実行する。

```bash
pnpm audit:posts
pnpm build
```

確認項目:

- `title` と `description` が検索意図を含んでいる
- `published` と必要に応じて `updated` がある
- `image` と `thumbnail` の実体が存在する
- `imageAlt` が説明的である
- `relatedLinks` が2件以上ある
- `sourceLinks` が必要な外部参照を持っている
- `faq` が2件以上ある
- 本文内に内部リンクがある
- 本文内に外部出典リンクがある
- 記事FAQの下に総合FAQへの不適切な誘導リンクがない
- 旧ドメイン `tony.effect.moe` と個人メールアドレスが残っていない

## 禁止事項

- 商品紹介だけの記事にする
- 外部ソースなしで、主張だけを積む
- 出典リンクを本文や `relatedLinks` から外す
- 記事FAQの下に、記事内容と対応していない総合FAQ・用語集リンクを置く
- サムネイルとヘッダーを同じ画像のトリミングだけで済ませる
- 架空の導入社数、実績、満足度を書く
- 成果保証に見える表現を書く
