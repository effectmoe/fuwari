## 3. このマップで一番怖い 2 つの事実

ぼくが散布図を見て**最初に脳が止まった事実**は次の 2 つだ。

### 事実 1：**「SEO」が議論軸からまるごと消えている**

2026 上半期版のマーケティング 35 キーワードに、**「SEO」という単語は1個も入っていない**。
コンテンツマーケや UGC のような周辺概念は中央群に残っているが、SEO そのものは「議論する価値があるトレンド」のリストから外された。
2010 年代のマーケ会議で SEO を抜きで戦略を組むなど考えられなかった人間にとって、この消失は地味だが決定的な変化を示している。

### 事実 2：**「LLMO・GEO・AEO・AIO」が将来性 4.15 の新しい島として左上に出現している**

代わりに浮上したのが、**LLMO（LLM最適化）/ GEO（Generative Engine Optimization）/ AEO（Answer Engine Optimization）/ AIO（AI Optimization）**を一括りにした新ノード。
将来性 **4.15**、経済インパクト **1.9** という座標は「将来性は高いが、まだお金になっていない」象限そのもので、これは新興技術カテゴリーが**収益化前**であることを示している。

→ 「**SEO は消えて、LLMO 群が新島として浮上した**」というたった 1 行の事実。これが本記事のすべての出発点だ。

次の章から、この 35 キーワードを DFB（Decompose / Frame / Build）で構造化していく。最終的に「2026 下半期にマーケターが取るべき行動指針」まで一直線に降りる。

## 4. DFB Step -1：依頼自体の構造化

DFB の最初の一歩は「サイクルを回す前に、依頼そのものを構造化する」こと[^2]。今回の依頼を 5 要素で抽出するとこうなる:

| 要素 | 抽出結果 |
|---|---|
| **主体** | ぼく（書き手）→ 読者（マーケター・経営者・AI 実装者） |
| **動詞**（複数）| ①読み解く ②予測する ③行動指針を導く（= 3 動詞 = 成果物 3 つ） |
| **対象** | 日経クロストレンド 2026 マーケトレンドマップ 35 キーワード |
| **暗黙制約** | 出典は明示する / 捏造禁止 / マップにない言葉を勝手に足さない / 提唱者ぶらない |
| **成果物数** | 3 個（俯瞰 / 予測 / 指針） |

つまり、本記事の出口は次の 3 点に固定される:

1. **構造化された俯瞰**（35 キーワードのテーマ別分布）
2. **2026 下半期の予測**（各ゾーンが半年後どう動くか）
3. **行動指針**（今日からマーケターが動かすべきレバー）

これ以外の成果物（フィージビリティ判定や工数見積もり、Kindle 構成案など）は**絶対に足さない**。これが [Step -1 で防ぐ失敗パターン G（Over-Delivery）](/dfb-complete-guide/#failure-patterns)に対する備えだ。

[^2]: [構造化ペディア「Step -1: 依頼自体の構造化」](/dfb-complete-guide/#step-minus-one)を参照。

## 5. DFB Step 0：Stop-Judge（I/S/T/D 宣言）

サイクル開始前に I/S/T/D を声に出す[^3]。

| 要素 | 宣言 |
|---|---|
| **I**（Intent）| **オブジェクト** — 「DFB の能力を見せる」（メタ）ではなく、「マーケ予測を実装する」（オブジェクト）。能力評価ではなく実行依頼として扱う。 |
| **S**（Scope）| **L3** — 既存フレーム（4 階層・能力のスライド）を**改造して**マップに当てる。L4（新フレーム創出）まで行かない。 |
| **T**（Time）| **記事 1 本ぶん** — およそ 7,000 字以内。連載なので、第 1 回で全部を語り尽くさない。 |
| **D**（Deliverable）| 上の章で確定した **3 個（俯瞰 / 予測 / 指針）** |

I を「オブジェクト」と宣言した時点で、次に書くべきものは**実行成果物**であって**理論解説**ではなくなる。提唱者として DFB を語りたい欲求はピラー記事[（構造化ペディア大全）](/dfb-complete-guide/)に閉じ込めて、本記事ではあくまで「マップに対する実装」に徹する。

[^3]: [構造化ペディア「Step 0: Stop-Judge」](/dfb-complete-guide/#stop-judge)を参照。

## 6. Decompose：35 語を 7 テーマグループに分ける

カオスを要素に分ける（因数分解）のが Decompose[^4]。
散布図のゾーン分布（上 / 中央 / 下）は「いま市場がどう評価しているか」を示してくれるが、**ぼくらが行動を起こすのに必要なのは、テーマグループ別の整理**だ。同じ「将来性高」の中でも、AI 関連と顧客体験では打ち手が完全に違うから。

35 キーワードを意味のかたまりで 7 グループに分けると、こうなる:

| グループ | 含まれるキーワード | 平均将来性 |
|---|---|---:|
| **🤖 AI ネイティブ群** | LLMO・GEO・AEO・AIO / AI エージェント / エージェンティックコマース / チャット bot | 高（3.9） |
| **📊 データ統合・運用基盤** | CDP・DMP / CRM / クッキー代替技術 / ジオターゲティング | 中〜高（3.4） |
| **👥 顧客体験 (CX) 群** | CX / EC / OMO・オムニチャネル / カスタマーサクセス / D2C / デジタル接客 / サブスクコマース | 中〜高（3.8） |
| **🎬 コンテンツ・メディア群** | 動画マーケ / 音声 SNS / UGC / コンテンツマーケ / インフルエンサーマーケ / ライブコマース / イマーシブ | 中（3.3） |
| **🎯 ターゲティング・パーソナライズ群** | パーソナライゼーション / 気象・季節マーケ / ソーシャルメディアマーケ | 中〜高（4.0） |
| **🏬 リアル接点・OMO 群** | デジタルサイネージ / 無人店舗 / リテールメディア / ファンベース | 中（3.4） |
| **⚓ 沈没・撤退候補群** | メタバース / SDGs / デザイン思考 / クラウドファンディング / ダイナミックプライシング / 運用型テレビ CM | 低（1.9） |

→ 35 個を**意味のかたまり**で扱えるようになった。次の Frame で、このグルーピングに**ぼく独自の枠（能力のスライド軸）**を被せて再解釈する。

## 7. Frame：「能力のスライド」軸で再解釈する

ぼくが提唱する [DFB の核心命題は「推論は AI に、構造化は人間に」](/dfb-complete-guide/#skill-shift)というものだ[^5]。
この命題を Decompose した 7 グループに当てると、トレンドマップの本当の意味が浮かび上がる。

枠の入れ替えは次の問いを通すだけでいい:

> 「このグループに含まれるキーワードは、**人間が AI に何をさせる枠**として浮上しているのか、それとも**AI が人間から奪っていく仕事**として浮上しているのか？」

この問いを 7 グループに当てた結果がこれだ:

| グループ | 能力のスライド軸での意味 | 2026 マーケでの位置 |
|---|---|---|
| 🤖 AI ネイティブ群 | **「AI に枠を与える側」が勝つ象限**。LLMO/GEO/AEO/AIO は「AI 検索エンジンに自社情報を読ませる」=（人間が）構造化する仕事の典型 | **将来性高 × 経済低** = 次の主戦場の入口 |
| 📊 データ統合・運用基盤 | 「AI に渡せる形でデータを整える」=（人間が）構造化する仕事 | 中〜高 = 既に主戦場 |
| 👥 顧客体験 (CX) 群 | EC/CX/CRM の運用は「AI が下支え、人間が体験設計」の住み分け | 高 × 高 = 既に稼ぎ頭 |
| 🎬 コンテンツ・メディア群 | 制作は AI が量産、人間は「企画と編集」のレイヤーに残る | 中 = 二極化中 |
| 🎯 ターゲティング・パーソナライズ群 | パーソナライゼーション将来性 4.85（マップ最高水準）は「個別最適化の枠を人間が設計」を意味する | 高 = 投資集中先 |
| 🏬 リアル接点・OMO 群 | デジタルサイネージ将来性 4.2 はリアル接点を AI で動かす象徴 | 中〜高 = 隠れた成長領域 |
| ⚓ 沈没・撤退候補群 | メタバース・SDGs・デザイン思考は「フレームだけ流行って AI 時代の枠にはまらなかった」群 | 低 = 撤退判断 |

→ **マップの将来性スコアと「能力のスライド」軸は、ぴったり一致する**。

「人間が AI に枠を与える側」の仕事は将来性 4.0 以上に集中し、「人間が AI と関係なく自走しようとした概念」（メタバース、SDGs、デザイン思考）は将来性 2.0 付近に沈んでいる。これは偶然ではなく、市場が**能力のスライドを暗黙に評価軸として採用している**ことを意味する。

そして決定的なのが、**SEO の消失と LLMO 群の浮上**だ。

| 過去 | 現在 |
|---|---|
| **SEO** = Google の検索アルゴリズムに合わせて、人間がコンテンツを最適化する | **LLMO/GEO/AEO/AIO** = AI（LLM）の引用文脈に合わせて、人間がコンテンツを構造化する |

主語も目的語も変わっていない。「人間が」「コンテンツを」「最適化する」。
変わったのは**最適化の対象が Google から LLM に置き換わったこと**だけだ。これは典型的な「能力のスライド」で、SEO というキーワードが消えたのは衰退したからではなく、**LLMO 群というより上位の概念に格上げされた**からと読むのが正しい。

[^5]: [構造化ペディア「能力のスライド」](/dfb-complete-guide/#skill-shift)を参照。

## 8. Build：2026 下半期のマーケ行動指針

Frame で得た「能力のスライド軸」を、具体的な打ち手に落とす。
ぼくは 4 つの行動指針に集約した。

### 行動 1：LLMO/GEO/AEO/AIO に「今から」自社を晒す

LLMO 群は将来性 4.15・経済インパクト 1.9 の象限にいる。「まだ儲からない」と言って様子見すれば、SEO 黎明期に出遅れたサイトと同じ末路をたどる。
具体的には、(1) llms.txt の整備、(2) 構造化データ（JSON-LD）の充実、(3) 一次情報としての出典明示、(4) AI 引用文脈に拾われやすい「定義の明確化」を、半年以内に実装すべきだ。

### 行動 2：AI エージェント × データ統合基盤 を組で投資する

AI エージェント（将来性 4.4）と CDP/DMP（将来性 4.8）はそれぞれ独立した投資先のように見えて、実は**1 つの軸**だ。「自社データを構造化して AI に動かしてもらう」という単一目的のための、データ層とエージェント層。
2026 下半期は、片方だけ買って失敗する案件が増える。両方を同時に走らせる体制を作るのが、勝ち筋になる。

### 行動 3：パーソナライゼーション × CX を「設計レイヤー」で握る

パーソナライゼーション将来性 4.85（マップ最高水準）、CX 将来性 4.5。この 2 つは「AI が自動でやってくれる領域」ではなく、**人間が体験全体を設計する領域**だ。
ここを失うと、AI 投資をいくら積んでも「データはあるけど使い道がない」状態に陥る。プロダクトマネージャー / マーケ部門の上位職に、設計責任を握らせるのが正解。

### 行動 4：メタバース・SDGs・デザイン思考 への投資は撤退判断

将来性 2.2 / 2.0 / 1.85 という数字は、市場が「ここに張った投資は回収できない」と判定した結果として読むべきだ。
継続中のプロジェクトがあるなら、半期内に「能力のスライド軸で生き残る要素」だけ抜き出して別案件に統合し、本体は撤退する。
これは「やめる勇気」ではなく、**より上位の枠（CX / AI ネイティブ群）に再投資する経営判断**だ。

## 9. 違和感察知と連載予告

DFB は 1 サイクル目に違和感が出るのが正常な動作だ[^6]。ぼくが組み終えて感じた違和感は 1 つだけある。

**「中央群（Y 2.5〜4.0）は半年後にどちらに動くのか？」**

ソーシャルメディアマーケ（Y 3.75）/ OMO（Y 3.65）/ コンテンツマーケ（Y 2.95）あたりは、現時点では「沈むとも上がるとも判別がつかない」中間地点にいる。
ぼくの仮説は、「**AI ネイティブ群との接続が早かったものだけ上ゾーンに引き上げられ、接続できなかったものは沈没群に落ちる**」というものだ。たとえばコンテンツマーケが LLMO と接続すれば 4.0 以上に浮上するし、接続できなければ 2026 末には SDGs と同じ象限に落ちる。
これは第 2 回（消費編）以降で定点観測していくテーマだ。
