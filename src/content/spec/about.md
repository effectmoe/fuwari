## 提唱する理論：DFB（Decompose / Frame / Build = 分・枠・組）

AI 時代に人間が身につけるべき思考メソッド。雑なプロンプトを 3 ステップで「LLM が完全に応えられる構造化命令」に変換する。

- **D**ecompose（分解）— 曖昧な要望を要素に分割する
- **F**rame（枠付け）— 役割・前提・制約・出力形式を明示する
- **B**uild（組立）— 必要な情報を構造化して LLM に渡す

ストアカで講座シリーズとして公開中:
- 講座①「攻略法編」（3,500円 / 60分）— ChatGPT/Claude を完全制御する構造化プロンプト理論
- 講座②「思想編」（5,500円 / 60分）— AI時代に人間が身につけるべき新スキル『DFB構造化メソッド』
